# ⌨️ Keycap

Press any key to see its JavaScript event.key, event.code, keyCode, modifiers and a ready-to-paste listener snippet.

**▶ Use it here: [https://drew-traldi.github.io/keycap-javascript-detection/](https://drew-traldi.github.io/keycap-javascript-detection/)**

- Free, no sign-up, no ads
- Runs entirely in your browser. Nothing you enter is sent to a server.
- Works on desktop and mobile

## Run it locally

It's a single HTML file. Download `index.html` and open it in any modern browser.
